# 验收记录（每个场景复制一份）

填写需求链接、负责人、日期、版本、配置、隔离数据位置、操作入口和清理方式。每项保留预期、实际、关联 ID 以及通过或待处理结论。

| 场景 | 核对点 |
| --- | --- |
| 正常操作 | 业务人员用正式入口完成任务，核对权威状态与用户反馈 |
| 越权及边界输入 | 拒绝写入，查询与日志均未泄露其他主体数据 |
| 重复及并发 | 同一请求重试结果一致，竞争写入满足唯一性或版本约束 |
| 中断与重启 | 在各持久化边界模拟中断，恢复后无遗漏、无重复副作用 |
| 外部超时 | 分清明确失败与送达未知，按关联 ID 对账 |
| 回滚与脱敏 | 验证备份可恢复，截图及日志移除凭据和个人信息 |
